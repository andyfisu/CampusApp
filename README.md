# CampusApp

## About

This GitHub repository contains a fictional **CampusApp** application created as part of the **Software Development Tools** course at **Centria University of Applied Sciences** in 2026.

The **Jira assignment** was completed as a pair project with my fellow student **Maria**, in accordance with the assignment requirements.

The code is merely intended to resemble the structure of a real software application and is not actually functional.

Approximately five seconds of development time were invested in this masterpiece. 😄

## Purpose

The purpose of this project was to practice using software development tools such as Git, GitHub, and Jira.

## Disclaimer

This is purely an educational project and is not intended for production use.
